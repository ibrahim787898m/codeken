# 💡 CodeKen

> A learning platform project that helps beginners learn programming interactively.

---

## 📖 Overview

**CodeKen** is an in-progress e-learning platform designed to make learning programming engaging and easy.  
It will feature interactive lessons, coding challenges, and community discussions.

---

## 🛠️ Tech Stack

- **Frontend:** React.js / HTML / CSS / JS
- **Backend:** Python / Flask
- **Database:** Firebase or MongoDB (planned)

---

## ⚙️ Planned Features

- 👨‍🏫 Course-based learning
- 💬 Discussion section
- 🧩 Code challenge system

---

## 🧠 Current Progress

Design structure & initial backend API planning are in progress.
